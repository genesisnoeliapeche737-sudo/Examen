# Página Web Sencilla

Proyecto básico realizado con **HTML, CSS y JavaScript**.

## Descripción

La página incluye:

- Un título principal.
- Una breve descripción.
- Una sección con información.
- Un botón interactivo.
- Un diseño sencillo, ordenado y responsive.

## Archivos

- `index.html`: contiene la estructura de la página.
- `style.css`: contiene los estilos y el diseño responsive.
- `script.js`: contiene la interacción del botón.
- `README.md`: explica el contenido del proyecto.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript

## Funcionamiento

Al hacer clic en el botón **“Conocer más”**, JavaScript cambia el texto de la sección principal.
