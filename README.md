# Página Web Sencilla

Este proyecto consiste en una página web sencilla desarrollada como práctica de **HTML, CSS y JavaScript**.

La página muestra un título, una sección con información y un botón interactivo. Al presionar el botón, JavaScript modifica el texto que aparece en pantalla.

## Tecnologías utilizadas

* **HTML:** para crear la estructura de la página.
* **CSS:** para agregar estilos, colores y organizar el contenido.
* **JavaScript:** para agregar interactividad a la página.

## Funcionalidades

* Página web sencilla y ordenada.
* Diseño adaptable a diferentes tamaños de pantalla.
* Botón interactivo.
* Cambio de texto mediante JavaScript.
* Cambio de color y estilo del texto al presionar el botón.

## Archivos del proyecto

* `index.html`: contiene la estructura principal de la página.
* `style.css`: contiene los estilos visuales.
* `script.js`: contiene la funcionalidad del botón.
* `README.md`: contiene la descripción del proyecto.

## Funcionamiento

Al abrir `index.html` se muestra la página principal.

Al hacer clic en el botón **“¡Haz clic aquí!”**, el mensaje:

`Haz clic en el botón para cambiar este mensaje.`

cambia a:

`¡El texto ha cambiado gracias a JavaScript!`

Además, el nuevo texto aparece en **negrita** y de color azul.
